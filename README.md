# BEN103 Jersey — ระบบพรีออเดอร์ (Google Sheets + Web App)

```
apps-script/
  Code.gs        ← โค้ดหลังบ้าน (วางใน Apps Script)
  Index.html     ← หน้าเว็บ (รูป/ฟอนต์ฝังในไฟล์แล้ว)
github-pages/    ← ใช้เฉพาะถ้าอยากวางหน้าเว็บบน GitHub Pages (ไม่บังคับ)
  index.html, img/, fonts/
```

## ติดตั้ง (ประมาณ 10 นาที)

1. สร้าง **Google Sheet ใหม่** ตั้งชื่อเช่น `BEN103 Orders`
2. ในชีต ไปที่เมนู **ส่วนขยาย → Apps Script**
3. ในไฟล์ `Code.gs` ลบโค้ดเดิมทิ้ง แล้ววางโค้ดจาก `apps-script/Code.gs`
4. กด **+ (เพิ่มไฟล์) → HTML** ตั้งชื่อว่า `Index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาจาก `apps-script/Index.html` ทั้งไฟล์
5. กด 💾 บันทึก
6. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน แล้วกด **เรียกใช้ (Run)**
   - ครั้งแรกจะขอสิทธิ์ → เลือกบัญชี → *ขั้นสูง* → *ไปที่ … (ไม่ปลอดภัย)* → *อนุญาต*
   - จะได้ชีต `Orders`, `Items`, `Summary` และโฟลเดอร์ `BEN103 Slips` ใน Google Drive
7. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
   - กด Deploy → คัดลอกลิงก์ที่ลงท้ายด้วย `/exec` → **นี่คือลิงก์เว็บพรีออเดอร์** ส่งให้ทุกคนได้เลย

> แก้โค้ดภายหลัง: ต้อง Deploy ใหม่ทุกครั้ง → *จัดการการทำให้ใช้งานได้* → ✏️ → เวอร์ชัน: *เวอร์ชันใหม่* → Deploy (ลิงก์เดิมไม่เปลี่ยน)

## การใช้งานหลังบ้าน

| ชีต | มีอะไร |
|---|---|
| **Orders** | 1 แถว = 1 ออเดอร์ · เลขออเดอร์ · ชื่อ · เบอร์ · การรับ/ที่อยู่ · รายการเสื้อ · ยอดเงิน · ลิงก์สลิป |
| **Items** | 1 แถว = เสื้อ 1 ตัว · ไซซ์ · ชื่อสกรีน · เบอร์ (ส่งโรงงานได้เลย) |
| **Summary** | นับจำนวนตัวแยกไซซ์ · จำนวนออเดอร์ · ยอดเงินรวม (ไม่นับออเดอร์ที่ยกเลิก) |

- **เปลี่ยนสถานะ** ที่คอลัมน์ `สถานะ` ในชีต Orders (เลือกจาก dropdown):
  `รอตรวจสลิป → ยืนยันแล้ว → กำลังผลิต → พร้อมรับ/จัดส่ง` หรือ `ยกเลิก`
  ลูกค้ากรอกเบอร์โทรในหน้า "เช็คออเดอร์" แล้วจะเห็นสถานะล่าสุดทันที
- **สลิป** เก็บในโฟลเดอร์ `BEN103 Slips` ชื่อไฟล์ = เลขออเดอร์_เบอร์โทร (เปิดดูได้เฉพาะเจ้าของ Drive)
- **ปิดรับอัตโนมัติ** หลัง 30 พ.ย. 2569 เวลา 23:59 น. (แก้ที่ `CONFIG.CLOSE_AT` ใน Code.gs)
- **ราคา/ค่าส่ง** แก้ที่ `CONFIG.PRICE`, `CONFIG.SHIP` ใน Code.gs **และ** `PRICE`, `SHIP` ใน Index.html ให้ตรงกัน
  (ระบบคิดยอดจริงจากฝั่ง Code.gs เสมอ หน้าเว็บแค่แสดงผล)

## (ไม่บังคับ) วางหน้าเว็บบน GitHub Pages

ถ้าอยากได้ลิงก์แบบ `xxx.github.io` แทนลิงก์ของ Google:

1. ทำขั้นตอนติดตั้งด้านบนให้ครบก่อน (ต้องมีลิงก์ `/exec`)
2. เปิด `github-pages/index.html` หาบรรทัด `var API_URL = '';` แล้วใส่ลิงก์ `/exec` ลงไป
3. อัปโหลดทั้งโฟลเดอร์ `github-pages/` ขึ้น repo แล้วเปิด GitHub Pages

ถ้าไม่ใส่ `API_URL` หน้าเว็บจะทำงานเป็นโหมด demo (เก็บออเดอร์ในเบราว์เซอร์เท่านั้น)
